# Aristocrat NET

Обход блокировок **без VPN-подписок и без своего сервера** для Android (телефоны и Android TV), Windows 7–11 и Linux.

Программа работает в два этапа:

1. **Обход DPI (локально, быстро).** Начало защищённого соединения (TLS ClientHello) нарезается так, чтобы ТСПУ провайдера не смог прочитать имя сайта: TLS-запись дробится, TCP-сегменты разбиваются, применяется disorder через TTL. DNS идёт через зашифрованный DoH (1.1.1.1, 8.8.8.8, 9.9.9.9). Скорость остаётся обычной.
2. **WARP или Tor (если сайт заблокирован по IP, DNS или обход DPI не помог).**
   - **Cloudflare WARP** — бесплатный зашифрованный WireGuard-туннель до ближайшего узла Cloudflare. Свой сервер не нужен: программа сама получает бесплатный аккаунт, как официальное приложение 1.1.1.1. Сайты видят IP Cloudflare, а не ваш. Против блокировки WireGuard перед рукопожатием отправляются мусорные пакеты (приём AmneziaWG), а узлы и порты перебираются, пока не найдётся рабочий.
   - **Tor** через мосты (в России и Казахстане прямой доступ к Tor заблокирован): автовыбор, snowflake, obfs4, meek или свои мосты из Telegram-бота @GetBridgesBot.

   По умолчанию сначала пробуется WARP, затем Tor. Сайт запоминается, и в следующий раз соединение сразу идёт нужным путём.

| Платформа | Интерфейс | Файл |
|---|---|---|
| Android 7+ (телефон, планшет, **Android TV**) | системный VPN для всех приложений; управление пультом | `AristocratNET-…-android-universal.apk` |
| Windows 7, 8, 8.1, 10, 11 (x86/x64) | нативное окно Windows + значок в трее; системный прокси | `AristocratNET-Setup-….exe`, `AristocratNET-Portable-…-windows.zip` |
| Linux x86_64 (Ubuntu 22.04+, Mint 21+, Debian 12, Fedora) | нативное окно (GTK/WebKitGTK) + значок в трее; системный прокси (GNOME/Cinnamon) | `obhod_…_amd64.deb`, `obhod-….x86_64.rpm` |

Главный экран: большая кнопка «Включить», под ней состояние («Шифрование включено») и ваш IP с флагом страны. «О программе» — справа сверху, настройки — шестерёнка слева снизу. Закрытие окна сворачивает программу в трей; выход — из меню значка в трее или в настройках.

В GNOME значок в трее появляется после установки расширения «AppIndicator and KStatusNotifierItem Support» (в Mint, KDE, XFCE работает сразу). Без него программа тоже работает: повторный запуск из меню открывает её окно.

## Как собрать (GitHub Actions)

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки:
   ```bash
   git init
   git add .
   git commit -m "Обход"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/obhod.git
   git push -u origin main
   ```
2. Откройте вкладку **Actions**: сборка запустится сама и займёт около 15–25 минут. Готовые файлы лежат внизу страницы запуска, в разделе **Artifacts** (`android`, `windows`, `linux`).
3. **Релиз со всеми файлами:** создайте тег.
   ```bash
   git tag v0.3.0
   git push origin v0.3.0
   ```
   На вкладке **Releases** появятся APK, EXE, DEB, RPM и SHA256SUMS.

### Подпись APK (желательно)

Без настройки APK подписывается временным debug-ключом, который при каждой сборке новый. Устанавливать такие APK можно, но **обновить поверх старой версии не получится** — придётся удалять старую. Чтобы обновления ставились, создайте свой ключ:

```bash
keytool -genkeypair -v -keystore release.jks -alias obhod -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 release.jks > release.jks.b64
```

Затем в **Settings → Secrets and variables → Actions** добавьте секреты:

- `ANDROID_KEYSTORE_BASE64` — содержимое `release.jks.b64`;
- `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища;
- `ANDROID_KEY_ALIAS` — `obhod`;
- `ANDROID_KEY_PASSWORD` — пароль ключа.

## Установка

- **Android / Android TV.** Установите `…-android-universal.apk`. Если APK нужен поменьше, выберите файл под архитектуру: `arm64-v8a` для большинства телефонов, `armeabi-v7a` для многих TV-приставок. Нажмите «Включить» и разрешите VPN. На TV всё управляется пультом. Поставить APK на TV можно с флешки, через «Send Files to TV» или `adb install`.
- **Windows.** Запустите `AristocratNET-Setup-….exe`. На Windows 7/8 установщик сам поставит совместимую версию Tor (13.5.x), на 10/11 — актуальную. Портативная версия (zip) работает везде без установки.
- **Linux.** `sudo apt install ./obhod_…_amd64.deb` или `sudo dnf install ./obhod-….x86_64.rpm`, затем запуск «Обход» из меню или командой `obhod`.

## Режимы

- **Авто** (по умолчанию) — обход DPI, при блокировке по IP — WARP или Tor (что именно — выбирается в настройках).
- **Только обход DPI** — без WARP и Tor. Самый быстрый режим, но сайты, заблокированные по IP, не откроются.
- **Всё через WARP** — весь трафик идёт через Cloudflare: другой IP-адрес, быстро.
- **Всё через Tor** — максимальная приватность, но медленнее.

**Местные сайты — с настоящим IP.** Российские и казахстанские сайты (зоны .ru, .рф, .su, .kz, .қаз, известные домены Яндекса, VK, банков, маркетплейсов, а также любые сайты, чьи серверы находятся в России или Казахстане — по базе GeoIP) всегда идут напрямую, даже в режимах «Всё через Tor» и «Всё через WARP». На Android банковские, государственные и подобные приложения по умолчанию работают мимо «Обхода» (список меняется в настройках).

**Spotify в России.** Spotify сам не работает для России. Если программа видит, что настоящий IP российский, Spotify (сайт и приложение) идёт через Tor даже в режиме «Авто». В Казахстане это правило не действует. Оба правила отключаются в настройках.

**Страна IP-адреса.** WARP меняет IP, но не страну: Cloudflare специально выдаёт адрес из вашей страны. Чтобы сайты видели IP из другой страны, выберите в настройках «Страна IP через Tor» (Германия, Нидерланды, США и другие) и режим «Всё через Tor».

На Android в настройках можно выбрать **приложения мимо «Обхода»**: банки, госуслуги, Яндекс Музыку и другие сервисы, которые не работают при включённом VPN или с чужим IP. Несколько таких приложений отмечены по умолчанию.

**Блокировка рекламы** (включена по умолчанию, во всех версиях). Соединения с рекламными и следящими серверами отклоняются, поэтому не загружаются баннеры, всплывающие окна, реклама в приложениях и играх (AdMob, Unity Ads, AppLovin, Яндекс и другие сети) и реклама букмекеров. Список фильтра AdGuard DNS обновляется сам раз в сутки, плюс встроенный список. Так же устроены AdGuard DNS и AdAway.

**Мосты Tor с телефона на телевизор.** При первом запуске программа предлагает получить мосты в Telegram-боте @GetBridgesBot: кнопки «Получить мосты» и «Я в Казахстане» (там мосты не нужны). Кнопка «Отправить» рядом со «Своими мостами» находит другие устройства с Aristocrat NET в той же сети Wi-Fi: телевизоры, телефоны и компьютеры. Мосты отправляются на выбранное устройство и сохраняются там только после подтверждения.

**YouTube без рекламы в России.** Google не продаёт рекламу в России, поэтому с российским IP YouTube идёт без рекламы. Если программа видит, что настоящий IP российский, YouTube всегда идёт с этим IP: напрямую с обходом замедления, а при неудаче — через WARP (он даёт IP той же страны). Через Tor YouTube не идёт, даже в режиме «Всё через Tor». Так и платные VPN делают «YouTube без рекламы»: трафик YouTube выходит в интернет через Москву. В Казахстане правило не действует.

**Домашняя сеть и раздача интернета (Android).** Адреса домашней сети и поиск устройств идут мимо VPN: Chromecast, Smart TV, принтеры, роутер. Поэтому трансляция на телевизор и управление им работают при включённой программе. Программа сама отвечает на DNS-запросы настоящими адресами, поэтому не пропадает интернет у устройств, подключённых к телефону по точке доступа. Для этих устройств обход блокировок не действует, у них обычный интернет телефона.

**Шторка, раздача и приём интернета (Android).** В шторке две кнопки (добавляются через редактирование шторки или кнопкой «Добавить кнопки в шторку» на экране «📶 Раздача интернета»): «Обход блокировок» (щит) — включает и выключает обход; «Раздача» (антенна) — предлагает «Раздача», «Раздача с обходом блокировок» или «Подключиться к раздаче», повторное нажатие выключает. Приём есть и на главном экране (кнопка «📡 Подключиться к раздаче») — для телевизоров, где шторки нет.
Как раздать без ограничения оператора: на телефоне с сим-картой — обычная точка доступа и «Раздача» (Wi-Fi включать не нужно); на втором устройстве (телефон, планшет, Android TV) — подключиться к точке доступа и включить «Подключиться к раздаче». Весь трафик второго устройства идёт в прокси первого телефона (порт 8282), а в интернет его отправляет сам телефон, поэтому оператор видит обычный трафик телефона, а не раздачу. Устройствам без Aristocrat NET нужно указать прокси в настройках сети (адрес телефона, порт 8282), иначе они пойдут обычной раздачей.

**Раздача и приём на ПК (Windows, Linux).** На главном экране — кнопки «Раздать интернет» и «Подключиться к раздаче», те же пункты есть в меню трея и в Настройки → «Раздача и приём».
- «Раздать интернет» (без обхода или с обходом блокировок): устройства сети компьютера (Wi-Fi роутера или «Мобильного хот-спота» Windows) включают у себя «Подключиться к раздаче» в Aristocrat NET или указывают прокси: адрес компьютера, порт 8282. Установщик Windows сам разрешает программе входящие подключения в брандмауэре.
- «Подключиться к раздаче»: компьютер подключается к точке доступа телефона с включённой «Раздачей»; программа сама находит телефон и пускает через него весь трафик системного прокси, а свои служебные соединения (DNS, внешний IP) — тоже через телефон. Программы, которые не используют системный прокси (некоторые игры), пойдут обычной раздачей.
- Android находит раздачу и на компьютере в домашней сети: «Подключиться к раздаче» ищет её сначала у роутера, потом по всей сети.

**Крестик окна (ПК).** Программа спрашивает: «Свернуть в трей» или «Выйти». Можно отметить «Запомнить выбор» и поменять его потом в «Настройки → При закрытии окна». Меню значка в трее на Windows оформлено в стиле программы.

**GNOME (Linux).** Значок в трее в GNOME показывает расширение AppIndicator. Пакет программы ставит его как рекомендуемую зависимость (gnome-shell-extension-appindicator), а программа при запуске сама его включает. Если значок не появился сразу, выйдите из системы и войдите снова.

**«Ебаная Чукотка» (раздача интернета через компьютер разработчика).** Интернет пользователей может выходить через компьютер разработчика с белым IP (Windows). Там работает тот же обход, что и у самого разработчика («Авто»): обход DPI, при блокировке — WARP или Tor, блокировка рекламы.

- **Сборки.** GitHub собирает три комплекта:
  - **для всех пользователей** — `android`, `windows`, `windows-setup`, `linux`: без маршрута «Ебаная Чукотка» и без подписи Edward Version;
  - **Edward Version** — `edward-android`, `edward-windows`, `edward-windows-setup`, `edward-linux`: с маршрутом «Ебаная Чукотка» и подписью Edward Version (на Android — зелёная надпись на главном экране);
  - **сборка разработчика** — `_dev-windows`, `_dev-linux`: ставится только на сервер и компьютер-выход. Её установщик сам открывает программе входящие подключения в брандмауэре Windows.
  Обе пользовательские версии — одно и то же приложение: Edward Version ставится поверх обычной и наоборот, настройки сохраняются.
- **Секреты репозитория** (Settings → Secrets and variables → Actions):
  - `DEV_PASSWORD` — пароль режима разработчика. В программу попадает только его хэш (PBKDF2).
  - `DEV_DIRECT` — код подключения (`d1:IP:порт:отпечаток:ключ`). Его показывает сборка разработчика: «Ключ и код подключения» → «Копировать код подключения». Пока секрета нет, маршрута «Ебаная Чукотка» у пользователей нет.
  - `DEV_CODE` больше не нужен — его можно удалить.
- **У разработчика:** Настройки → «Режим разработчика» (по паролю) → «Раздача интернета». Также значок антенны на главном экране и переключатель в меню трея. Нужен белый IP и открытый порт 443 (если занят — 8443; у провайдера облачного сервера порт открывают в его панели). Ключ сервера (сертификат и ключ доступа) можно копировать, сохранить в файл или в облако и восстановить — после переустановки код подключения останется прежним. Журнал подключений показывает имя устройства, IP, город и страну, версию приложения и трафик каждого пользователя.
- **Выход через другой компьютер (без белого IP).** Чтобы сайты видели не IP сервера, а IP другого компьютера разработчика (например, в Казахстане), поставьте на него сборку разработчика и включите «Выход в интернет через этот компьютер». Компьютер сам подключится к серверу и будет держать готовые соединения; схема: пользователь → сервер (Москва) → компьютер-выход → сайт. Пока выход не подключён, сервер открывает сайты сам. Пароль разработчика (секрет `DEV_PASSWORD`) у сервера и выхода должен быть один — обе сборки из одного репозитория.
- **У пользователя:** Настройки → «Режим работы» → «Ебаная Чукотка». Перед включением пользователь видит предупреждение о том, какие сведения увидит разработчик. Если сервер недоступен, программа работает как в «Авто».

## Ограничения (честно)

- **Реклама внутри роликов YouTube и SponsorBlock.** Ролики YouTube и реклама в них идут с одних и тех же серверов, а соединение зашифровано. Поэтому ни программа, ни AdGuard DNS не могут убрать такую рекламу, не ломая само видео. Её убирают только в самом проигрывателе: на телевизоре и Android — **SmartTube** (бесплатный клиент YouTube со встроенной блокировкой рекламы и SponsorBlock), на ПК — расширения браузера **uBlock Origin** и **SponsorBlock**. Остальную рекламу на сайтах YouTube и Google программа блокирует.
- **«Частный DNS» на Android** (Настройки → Сеть → Частный DNS) отправляет имена сайтов мимо программы, и блокировка рекламы видит меньше. Лучше выключить его или поставить «Автоматически».

- **Tor медленнее прямого соединения.** Для видео в высоком качестве он подходит плохо, зато сайты, заблокированные по IP, через него открываются.
- **Некоторые сайты блокируют вход из Tor** (банки, часть магазинов). Их стоит оставить напрямую: российские сайты и так не заблокированы и идут напрямую.
- **Режим «белых списков»** на мобильном интернете может закрыть и Tor-мосты. Тогда попробуйте другой тип моста или свои мосты из @GetBridgesBot.
- **UDP/QUIC.** На Android UDP (голосовые и видеозвонки, игры) передаётся напрямую, в режиме «Всё через WARP» — через WARP. QUIC (UDP на порт 443) намеренно не пропускается: браузеры и приложения сразу переходят на TCP, где работает обход блокировок. На ПК в Chrome стоит отключить QUIC: chrome://flags → Experimental QUIC protocol → Disabled.
- **WARP** в некоторых регионах России тоже блокируют. Тогда программа продолжит перебирать узлы в фоне, а сайты пойдут через Tor.

## Устройство проекта

```
core/        ядро на Go (общее для всех платформ): прокси, обход DPI, DoH, управление Tor, веб-интерфейс
android/     приложение для Android/TV (Java): VpnService + hev-socks5-tunnel + tor-android + ядро
packaging/   установщик Windows (Inno Setup), пакеты Linux (nfpm → deb/rpm)
scripts/     загрузка Tor Expert Bundle, сборка нативных частей Android
assets/      иконки
.github/workflows/build.yml — сборка всего
```

Используемые открытые компоненты:

- [wireguard-go](https://git.zx2c4.com/wireguard-go) и [gVisor](https://gvisor.dev/) (туннель WARP);
- [Tor](https://www.torproject.org/) (Tor Expert Bundle; [tor-android](https://github.com/guardianproject/tor-android));
- [lyrebird](https://gitlab.torproject.org/tpo/anti-censorship/pluggable-transports/lyrebird) (obfs4, webtunnel, snowflake);
- [hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel).

Сборка ядра для Windows идёт на Go 1.20 — последней версии, программы которой запускаются на Windows 7.

Локальная проверка ядра:

```bash
cd core && go test ./...
```
